ОДЕРЖИМЫЕ — v56.2.4, мобильная анимация и проявление цифр

Исправлено:
- Мобильный двойной шар: статический CSS-корпус теперь скрывается в том же кадре, в котором появляется готовое видео.
- Убрано плавное смешивание MP4 с неподвижной сферой, вызывавшее фантомный силуэт при движении.
- Начало CSS-траектории шара синхронизируется со временем первого декодированного кадра видео.
- Завершение фаз связано с фактическим окончанием клипа, а не с отдельным таймером от момента запуска HTMLVideoElement.
- При временной буферизации движение MP4 и его CSS-смещение приостанавливаются согласованно; на случай зависания оставлен тайм-аут.
- Лишние эффекты CSS-3D во время показа видеокадров отключены.
- Проявление цифры в финале на десктопе ускорено незначительно (полная видимость примерно на 80–90 мс раньше); длительность и траектория броска не менялись.

НЕ менялись: игровой алгоритм, материал и отражения корпуса, последовательность броска, видеофайлы 918x918, внешний вид остальных экранов.

GitHub Pages — полная версия:
1. Распакуйте ZIP на компьютер.
2. Загружайте в корень репозитория все файлы И папку assets, чтобы index.html лежал в корне.
3. Commit changes; подождите публикации на GitHub Pages.
4. Откройте сайт с обновлением страницы (при необходимости в приватной вкладке).

GitHub Pages — установка одним файлом:
Используйте отдельный ODERZHIMYE_v56_2_4_GITHUB_ONEFILE/index.html. Это самодостаточная версия, она больше по размеру, потому что MP4 встроены внутрь HTML.

Предпочтительно использовать полную сборку на iPhone: отдельные MP4 получают HTTP byte-range ответы и не раздувают HTML.

Проверка: три последовательных броска на мобильных конфигурациях 320, 390 и 740 px в Chromium, завершение всех фаз и восстановление живого шара, проверка синтаксиса JavaScript. Физический iPhone с Safari не тестировался.
