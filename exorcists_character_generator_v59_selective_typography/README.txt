БИТВА ЭКЗОРЦИСТОВ — ОДЕРЖИМЫЕ
v59 / 1.4.0 — точечная настройка шрифтов по запросу

ВЕРСИИ ГАРНИТУР
• Exorcists Angular (v58) — только название «ОДЕРЖИМЫЕ», все заголовки
  книги сущностей, надписи «ВЫБЕРИТЕ РЕЖИМ», «МАГИЧЕСКИЙ ШАР» внутри
  окна шара (но не на кнопке) и надписи со словом «ИГРОК» / «ИГРОКИ».
• Ruslan Display (v57) — все видимые цифры в акцидентных заголовках,
  счётчиках, индикаторах и игровых вкладках. Цифровая гарнитура загружается
  по сети с лицензированного Fontsource CDN (при недоступности CDN
  применяется прежний запасной шрифт); текстовые буквы остаются прежними.
• Impact (v56, до изменений типографики) — все остальные заголовки,
  кнопки, подписи и акцидентные элементы. Обычный текст сохраняет
  исходные шрифтовые семейства для удобства чтения.

НАСТРОЙКИ
Остальные стили, текстуры, логика, 3D, движение шара и анимации
сохранены от v58 без изменений. Классы для имён «Игрок»/«Игроки»
назначаются в существующих функциях рендера, без MutationObserver.

РАЗВЁРТЫВАНИЕ
Загрузите ZIP на Netlify: index.html расположен в корне.
Номер релиза, файлы стилей, JS и ключ service-worker кеша обновлены.
См. QA_REPORT.txt для размеров экранов и проверенных экранов.
